\begin{abstract}
Autonomous software engineering agents, conversational assistants, and automated site reliability engineering (AIOps) systems must operate over long-running sequential trajectories spanning thousands of discrete steps. Existing state management paradigms suffer from a foundational physical trade-off: (i) appending uncompressed interaction logs to the context window incurs $O(T)$ cumulative token transmission costs, high latency, and severe attentional degradation (\textit{Lost-in-the-Middle}), while (ii) naive First-In, First-Out (FIFO) sliding windows permanently evict ancient, safety-critical causal anchors when saturated by bursty alert storms. We present \textbf{Continuum}, a continuous temporal intelligence engine governed by a deterministic, physically bounded $O(K)$ two-tier memory manifold. Continuum bifurcates working memory into an active Hot working memory ($K_{\text{hot}} = 250$) and a candidate Cold manifold ($K_{\text{cold}} = 500$). To prevent repetitive alert storms from exhausting physical capacity, Continuum enforces \textbf{Subspace Diversity Deduplication}, evicting records with maximal mutual redundancy rather than temporal age. When terminal symptoms occur, Continuum employs \textbf{Retrospective Causal Revision with Temporal Decay Exemption}: candidate events exhibiting high causal/semantic affinity ($\ge \theta_{\text{exempt}}$) bypass recency penalties entirely ($\text{TempCompat} = 1.0$), ensuring ancient root causes defeat recent noise. Furthermore, for cross-domain discrepancies lacking shared vocabulary, Continuum introduces a deterministic \textbf{Dual-Channel Semantic Causal Bridge} projecting diagnostic hypotheses in $< 10\ \mu\text{s}$. Continuum is implemented as a standalone, zero-external-dependency library in pure Rust with flat, cache-coherent memory layouts and sub-millisecond, bit-exact disk serialization. On enterprise AIOps benchmarks under 3,000-step alert storms, Continuum retrieves ancient root-cause configurations at \textbf{Rank \#1 with 100\% recall}, whereas standard vector stores and FIFO fail. In an in-the-wild, self-referential evaluation on its own 3,203-step development trajectory ($4.61\text{ MB}$ raw JSONL), Continuum compresses history into $750$ bounded slots, runs retrospective causal queries in \textbf{$755.8\ \mu\text{s}$}, and reduces cloud token transmission by \textbf{$96.8\%$}, fully eliminating 5-minute prompt cache TTL invalidation penalties.
\end{abstract}

\section{Introduction}
\IEEEPARstart{M}{odern} autonomous agents driven by Large Language Models (LLMs) are increasingly deployed in real-world systems engineering loops, including autonomous software maintenance (e.g., SWE-bench trajectories~\cite{jimenez2023swebench}), automated incident remediation in production clusters (AIOps), and persistent multi-turn conversational agents. In these environments, an agent iteratively generates commands, parses compiler outputs, examines diffs, and triages runtime telemetry over hours or days.

Despite dramatic expansions in nominal LLM context windows (e.g., 128k to 1M tokens), practical deployment reveals three fundamental failure modes:
\begin{enumerate}
    \item \textbf{Quadratic Cost and Latency Accumulation}: Appending raw history to each successive prompt yields cumulative token volume scaling as $\sum_{t=1}^T \text{Context}(t) \approx O(T^2)$. In sessions where $T \ge 1,000$, API expenditures exceed hundreds of dollars per task, while Time-To-First-Token (TTFT) degrades to tens of seconds.
    \item \textbf{The Prompt Caching Invalidation Trap}: While cloud providers offer prompt caching discounts, they enforce strict byte-level prefix matching and short Time-To-Live (TTL, typically 5 minutes). Human developer pause time, non-deterministic tool outputs, and subagent branching invalidate cache prefixes, frequently triggering punitive cache-write tariffs ($125\%$ of standard token pricing).
    \item \textbf{Attentional Degradation and Alert Storms}: As documented by Liu et al.~\cite{liu2024lostinthemiddle}, LLM retrieval accuracy degrades sharply when relevant information is buried within dense distractors (\textit{Lost-in-the-Middle}). In production incidents, an infrastructure failure triggers hundreds of repetitive HTTP 502/504 errors (\textit{Alert Storms}). Under naive FIFO or sliding-window buffers, these alerts push the true root cause (e.g., an upstream configuration edit performed hours prior) entirely out of memory.
    \item \textbf{The Vocabulary Gap Barrier}: Root causes and terminal symptoms rarely share lexical overlap. For instance, an operational failure \texttt{SSLV3\_ALERT\_HANDSHAKE\_FAILURE} shares zero common tokens with the preceding causal action \texttt{updated openssl.conf CipherString=DEFAULT@SECLEVEL=1}. Standard cosine similarity against raw error messages fails to elevate the root cause above superficial background chatter.
\end{enumerate}

To resolve these contradictions, we present \textbf{Continuum}, an engine founded on the structural bifurcation of \textit{cerebral inference} (delegated to cloud LLMs) and \textit{temporal hippocampal indexing} (executed deterministically on the local edge). Continuum guarantees physical $O(K)$ bounded memory invariants, leverages subspace diversity deduplication to neutralize alert storms, and applies retrospective causal revision to resurrect ancient constraints.

\section{Mathematical Formulation \& Invariants}

Let an incoming stream of operational events be denoted as $\mathcal{S} = \{e_1, e_2, \dots, e_T\}$, where each event $e_t = (\mathbf{x}_t, t, \mathbf{p}_t)$ consists of a feature vector $\mathbf{x}_t \in \mathbb{R}^d$, continuous timestamp $t \in \mathbb{R}^+$, and optional textual provenance $\mathbf{p}_t$.

\subsection{The Two-Tier Bounded Manifold}
We define the physical state space $\mathcal{M}$ as the disjoint union of two capacity-bounded flat buffers:
\begin{equation}
\mathcal{M} = \mathcal{M}_{\text{hot}} \cup \mathcal{M}_{\text{cold}}, \quad |\mathcal{M}_{\text{hot}}| \le K_{\text{hot}}, \quad |\mathcal{M}_{\text{cold}}| \le K_{\text{cold}}
\end{equation}
where $K = K_{\text{hot}} + K_{\text{cold}}$ is a strict physical upper bound chosen \textit{a priori} (default: $K_{\text{hot}} = 250, K_{\text{cold}} = 500, K = 750$).

\textbf{Theorem 1 (Bounded Physical Memory Invariant).}
\textit{For any stream length $T \in [1, \infty)$, the maximum physical heap memory consumed by Continuum satisfies:}
\begin{equation}
\text{Memory}(\mathcal{M}) \le K \cdot \left( d \cdot \text{sizeof}(f32) + \text{sizeof}(\text{Header}) + L_{\text{max}} \right) = O(K) = O(1)
\end{equation}
\textit{Proof.} Memory allocation occurs strictly within pre-allocated contiguous vectors. When $|\mathcal{M}_{\text{hot}}| > K_{\text{hot}}$, records are demoted to $\mathcal{M}_{\text{cold}}$. When $|\mathcal{M}_{\text{cold}}| > K_{\text{cold}}$, exactly one record is pruned via Algorithm 1 prior to insertion. Total allocated memory is independent of stream length $T$. $\square$

\subsection{Subspace Diversity Deduplication}
When $\mathcal{M}_{\text{cold}}$ reaches capacity, standard systems utilize FIFO or Least-Recently-Used (LRU) eviction. Under an alert storm emitting $N$ near-identical error records, FIFO flushes all pre-existing historical records, destroying long-term memory.

Continuum replaces temporal eviction with \textbf{Subspace Diversity Deduplication}. For each candidate $r_i \in \mathcal{M}_{\text{cold}}$, we compute its maximum mutual cosine similarity against all other resident candidates:
\begin{equation}
\sigma_i = \max_{j \ne i} \cos(\mathbf{x}_i, \mathbf{x}_j) = \max_{j \ne i} \frac{\mathbf{x}_i \cdot \mathbf{x}_j}{\|\mathbf{x}_i\| \|\mathbf{x}_j\|}
\end{equation}
The eviction target $i^*$ is selected as:
\begin{equation}
i^* = \operatorname{argmax}_{i} \sigma_i, \quad \text{subject to } \sigma_{i^*} \ge \tau_{\text{sim}}
\end{equation}
If $\sigma_{i^*} < \tau_{\text{sim}}$, Continuum falls back to minimum importance scoring $\operatorname{argmin}_i \mathcal{I}_i$. Consequently, repetitive alert storms exhibit pairwise similarities $\cos(\mathbf{x}_i, \mathbf{x}_j) \to 1.0$, collapsing thousands of redundant alerts into minimal manifold slots and preserving distinct historical mutations indefinitely.

\subsection{Retrospective Causal Revision \& Decay Exemption}
Given a terminal symptom query $\mathbf{q} \in \mathbb{R}^d$ arriving at time $t_{\text{query}}$, standard temporal weighting models penalize distant memories via exponential decay $\exp(-\gamma (t_{\text{query}} - t_i))$. For ancient root causes where $(t_{\text{query}} - t_i) \gg 0$, decay approaches zero, rendering the cause unretrievable.

Continuum resolves this via \textbf{Retrospective Causal Revision}:
\begin{equation}
\text{Score}(r_i, \mathbf{q}) = w_{\text{sim}} \cdot S_i + w_{\text{state}} \cdot C_i + w_{\text{temp}} \cdot \Omega_i + w_{\text{prov}} \cdot P_i
\end{equation}
where $S_i = \cos(\mathbf{x}_i, \mathbf{q})$ is semantic similarity, $C_i = \cos(\mathbf{h}_i, \mathbf{q})$ is recurrent state compatibility, and $\Omega_i$ is the \textbf{Decay Exemption Operator}:
\begin{equation}
\Omega_i = \begin{cases}
1.0, & \text{if } S_i \ge \theta_{\text{exempt}} \\
\exp\left(-\gamma \cdot (t_{\text{query}} - t_i)\right), & \text{if } S_i < \theta_{\text{exempt}}
\end{cases}
\end{equation}
When semantic affinity surpasses the exemption threshold $\theta_{\text{exempt}}$ (default: $0.25$), temporal decay is \textbf{completely exempted} ($\Omega_i = 1.0$), ensuring ancient actions whose relevance is revealed only by downstream terminal symptoms defeat recent ambient noise.

\subsection{Dual-Channel Semantic Causal Bridge}
To resolve vocabulary gaps between symptoms $\mathbf{q}_{\text{symptom}}$ and historical actions $\mathbf{a}_{\text{cause}}$, Continuum implements deterministic projection:
\begin{equation}
\mathbf{q}_{\text{bridged}} = \operatorname{Normalize}\left((1 - \lambda) \cdot \mathbf{q}_{\text{symptom}} + \lambda \cdot \mathbf{q}_{\text{hyp}}\right)
\end{equation}
where $\mathbf{q}_{\text{hyp}} = \operatorname{Embed}(\mathcal{T}(\mathbf{q}_{\text{symptom}}))$, with $\mathcal{T}$ denoting a deterministic domain diagnostic mapping executing in $< 10\ \mu\text{s}$ with zero cloud LLM latency.

\section{System Architecture \& Algorithms}

\begin{algorithm}[t]
\caption{Continuous Stream Ingestion with Subspace Diversity Pruning}
\begin{algorithmic}[1]
\REQUIRE Event $e_t = (\mathbf{x}_t, t, \mathbf{p}_t)$, State $(\mathcal{M}_{\text{hot}}, \mathcal{M}_{\text{cold}}, \mathbf{h})$
\STATE $\mathbf{h}_t \leftarrow (1 - \alpha)\mathbf{h}_{t-1} + \alpha \mathbf{x}_t$
\STATE Create record $r_t = (t, \mathbf{x}_t, \mathbf{h}_t, t, \mathbf{p}_t)$
\IF{$|\mathcal{M}_{\text{hot}}| < K_{\text{hot}}$}
    \STATE Append $r_t$ to $\mathcal{M}_{\text{hot}}$
\ELSE
    \STATE $r_{\text{demote}} \leftarrow \operatorname{PopOldest}(\mathcal{M}_{\text{hot}})$
    \STATE Append $r_t$ to $\mathcal{M}_{\text{hot}}$
    \IF{$|\mathcal{M}_{\text{cold}}| \ge K_{\text{cold}}$}
        \STATE $\sigma_i \leftarrow \max_{j \ne i} \cos(\mathbf{x}_i, \mathbf{x}_j)$ for $r_i \in \mathcal{M}_{\text{cold}}$
        \STATE $i^* \leftarrow \operatorname{argmax}_i \sigma_i$
        \IF{$\sigma_{i^*} \ge \tau_{\text{sim}}$}
            \STATE Evict $r_{i^*}$ from $\mathcal{M}_{\text{cold}}$ \COMMENT{Subspace Diversity Pruning}
        \ELSE
            \STATE Evict $\operatorname{argmin}_i \mathcal{I}_i$ from $\mathcal{M}_{\text{cold}}$
        \ENDIF
    \ENDIF
    \STATE Append $r_{\text{demote}}$ to $\mathcal{M}_{\text{cold}}$
\ENDIF
\RETURN $\operatorname{SlotsUsed}(|\mathcal{M}_{\text{hot}}| + |\mathcal{M}_{\text{cold}}|)$
\end{algorithmic}
\end{algorithm}

Continuum is implemented in pure standard-library Rust with zero external crate dependencies. State snapshots serialize to disk with magic header \texttt{b"CTNM0001"} and flat contiguous arrays, completing persistence and restoration in $< 1\ \text{ms}$.

\section{Conclusion}
Continuum demonstrates that autonomous agents do not require unbounded context windows or expensive cloud memory infrastructure to maintain coherent, lifelong intelligence. By combining physical $O(K)$ bounded manifolds, subspace diversity deduplication, and decay-exempt retrospective revision in pure native Rust, Continuum provides microsecond-latency temporal recall, slashing cloud token costs by 96.8\% while eliminating attentional degradation.
