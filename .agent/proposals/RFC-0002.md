## 1. Problem and Strategic Intent

In an unbounded continuous event stream $x_1, x_2, \dots, x_T$ ($T \gg 10^6$), a system with physically bounded storage cannot retain full event activations or raw representations. 

Phase 2 established `TemporalState`: a bounded $H$-dimensional continuous recurrent state. While `TemporalState` effectively tracks short-term temporal dynamics and local context, it is fundamentally bounded in capacity; information outside its immediate recurrent window decays exponentially (catastrophic forgetting / representation dilution).

To achieve long-range retrieval without unbounded memory growth ($O(T)$), Continuum requires an **Adaptive Memory** layer that makes discrete, irrevocable online decisions at each time step $t$:
1. Which events contain high-value epistemic or relational information warranting long-term retention?
2. Which events are redundant or predictable and can be safely discarded or compressed?

### Baseline Implementation Complexity Notice (Phase 3 Constraint)
> [!IMPORTANT]
> **Phase 3 Baseline Complexity vs. Final Scalability:**  
> In this Phase 3 initial implementation, Novelty calculation performs an exhaustive comparison against the active memory bank, resulting in $O(K \cdot D)$ per event, and eviction without a min-heap operates in $O(K)$ ($O(\log K)$ with heap).  
> **This $O(K \cdot D)$ complexity is strictly a Phase 3 baseline implementation property and MUST NOT be claimed as Continuum's final scalable complexity.**  
> Sub-linear search and scalable retrieval over large $K$ are explicitly deferred to **Phase 4 (Sparse Event Memory)**.

### Falsifiable Strategic Hypothesis
> **Hypothesis H-002**: Given a strict memory budget $K \ll T$, an online adaptive retention policy based on predictive surprise, structural novelty, and uncertainty will achieve statistically significant higher retrieval accuracy ($p < 0.01$) on distant critical events than fair memory baselines (Random eviction, FIFO, LRU), while maintaining strictly bounded space $O(K \cdot D)$ and per-step processing time $O(K \cdot D)$.

### Strategic Discipline & Pre-Registered Equal-Weight Baseline
Adaptive Memory is not an excuse to stack arbitrary heuristics.
- **Pre-Registered Canonical Configuration:** The primary multi-factor model is locked to equal weights:
  $$\alpha = \beta = \gamma = \delta = \epsilon = 0.2$$
  Tuning weights after inspecting benchmark results is strictly prohibited; any post-hoc parameter exploration must be archived as separate exploratory experiments.
- **Parsimony Mandate:** If empirical ablations demonstrate that a simple single-factor model (e.g., Novelty alone or Surprise alone) matches or outperforms the five-factor composite model, the extraneous factors **must be excised**.
- **Phase 6 Skepticism:** Phase 6 ("Phase-Aware Interaction") remains unvalidated; Phase 3 architecture must operate completely independently of any phase assumptions.

## 2. EventRecord Specification and Field Taxonomy

Every event observed by Adaptive Memory is represented as an immutable `EventRecord`. To guarantee scientific integrity and prevent data contamination, all fields are strictly partitioned into four epistemic categories:

```text
+--------------------------------------------------------------------------------+
|                                  EventRecord                                   |
+--------------------+---------------------+-------------------+-----------------+
| 1. OBSERVED        | 2. DERIVED          | 3. PREDICTED      | 4. EVAL-ONLY    |
| (Stream Input)     | (Online Computed)   | (Model Estimated) | (FORBIDDEN)     |
+--------------------+---------------------+-------------------+-----------------+
| - event_id         | - surprise (S_t)    | - proxy_causal    | - future_query  |
| - timestamp        | - novelty (N_t)     |   (C_t)           | - target_label  |
| - embedding        | - uncertainty (U_t) | - retrieval_prob  | - ground_truth  |
| - payload_ref      | - importance (I_t)  |   (R_t)           | - task_solution |
|                    | - decision          |                   |                 |
|                    | - provenance        |                   |                 |
+--------------------+---------------------+-------------------+-----------------+
```

### Strict Prohibition of Evaluation-Only Contamination
> [!CAUTION]
> **RULE-013 (Anti-Leakage Constitution):**  
> Fields marked **EVALUATION-ONLY** (such as downstream test queries, benchmark answers, or future event horizons) must NEVER be passed into `EventRecord`, `AdaptiveMemory.observe()`, or any retention policy. Any unit test, harness, or pipeline that passes evaluation targets to the memory engine will immediately trigger a critical harness failure (`ContaminationError`).

### Python Typing & Data Contract

```python
from dataclasses import dataclass, field
from enum import Enum
from typing import Any, Literal
import torch
from torch import Tensor

class RetentionDecision(str, Enum):
    KEEP = "keep"          # Stored into primary active memory bank
    DISCARD = "discard"    # Dropped permanently; metadata preserved in telemetry if configured
    COMPRESS = "compress"  # Merged into cluster centroid or compressed representation

@dataclass(frozen=True)
class EventRecord:
    # 1. Observed fields (strictly at or before time t)
    event_id: int
    timestamp: float
    embedding: Tensor              # Shape: [D], float32, normalized
    payload_ref: str | None = None # Hash or pointer to raw external data (not retained in memory)

    # 2. Derived online metrics (computed at time t without lookahead)
    surprise: float = 0.0          # S_t in [0.0, 1.0]
    novelty: float = 0.0           # N_t in [0.0, 1.0]
    uncertainty: float = 0.0       # U_t in [0.0, 1.0]
    importance: float = 0.0        # I_t in [0.0, 1.0]
    decision: RetentionDecision = RetentionDecision.DISCARD
    provenance: dict[str, Any] = field(default_factory=dict)

    # 3. Predicted future relevance (strictly conditioned on x_{<=t})
    proxy_causal_score: float = 0.0    # C_t in [0.0, 1.0] (Explicitly marked proxy)
    retrieval_probability: float = 0.0 # R_t in [0.0, 1.0] (Strictly backward-looking predictor)

    def __post_init__(self) -> None:
        # Validate tensor invariants
        if not isinstance(self.embedding, Tensor):
            raise TypeError(f"embedding must be a torch.Tensor, got {type(self.embedding)}")
        if self.embedding.ndim != 1:
            raise ValueError(f"embedding must be 1D [D], got shape {self.embedding.shape}")
        if not torch.isfinite(self.embedding).all():
            raise ValueError(f"embedding for event {self.event_id} contains non-finite values")
        # Validate bounded metrics
        for name, val in [
            ("surprise", self.surprise),
            ("novelty", self.novelty),
            ("uncertainty", self.uncertainty),
            ("importance", self.importance),
            ("proxy_causal_score", self.proxy_causal_score),
            ("retrieval_probability", self.retrieval_probability),
        ]:
            if not (0.0 <= val <= 1.0):
                raise ValueError(f"Metric {name} must be in [0.0, 1.0], got {val}")
```

## 3. Mathematical Formulation of the Five-Factor Model

The composite importance score $I_t \in [0, 1]$ is parameterized by:

$$
I_t = \alpha S_t + \beta N_t + \gamma C_t + \delta R_t + \epsilon U_t
$$

Subject to the convex normalization constraint:
$$
\alpha, \beta, \gamma, \delta, \epsilon \ge 0, \quad \alpha + \beta + \gamma + \delta + \epsilon = 1.0
$$

All weights must be explicitly configurable via `AdaptiveMemoryConfig`. No hard-coded weighting is permitted.

---

### Factor 1: Surprise ($S_t$) — Temporal Prediction Error

* **Conceptual Definition:** The degree to which event $x_t$ violates the forward temporal prediction generated by the current continuous state $h_{t-1}$.
* **Mathematical Formulation:**  
  Let $h_{t-1}$ be the hidden state from `TemporalState`. A linear predictive head outputs expected candidate embedding $\hat{x}_t = W_{\text{pred}} h_{t-1} + b_{\text{pred}}$.  
  The squared prediction error is mapped to $[0, 1)$ via Gaussian radial basis / negative exponential:
  $$
  e_t = \|x_t - \hat{x}_t\|_2^2
  $$
  $$
  S_t = 1.0 - \exp\left(-\frac{e_t}{2 \sigma_s^2}\right) \in [0.0, 1.0)
  $$
  where $\sigma_s > 0$ is a running adaptive scale parameter (e.g., exponential moving average of recent prediction errors).
* **Online Computability:** Fully online; requires only $h_{t-1}$ and current input $x_t$.
* **Time Complexity:** $O(H \cdot D + D)$ operations.
* **Leakage Risk:** **Zero**. Strictly depends on past state $h_{t-1}$.

---

### Factor 2: Novelty ($N_t$) — Memory Space Orthogonality

* **Conceptual Definition:** The degree to which event $x_t$ differs from all representations currently residing in the active memory bank $\mathcal{M}_{t-1} = \{m_1, m_2, \dots, m_{|\mathcal{M}|}\}$.
* **Mathematical Formulation:**  
  Assuming $L_2$-normalized embeddings $\|x_t\|_2 = 1$ and $\|m_j\|_2 = 1$:
  $$
  \text{sim}_{\max}(x_t, \mathcal{M}_{t-1}) = \begin{cases} 
  0.0, & \text{if } |\mathcal{M}_{t-1}| = 0 \\
  \max_{m_j \in \mathcal{M}_{t-1}} \left(x_t^\top m_j\right), & \text{otherwise}
  \end{cases}
  $$
  Cosine similarity $\in [-1.0, 1.0]$ is mapped to distance in $[0.0, 1.0]$:
  $$
  N_t = \frac{1.0 - \text{sim}_{\max}(x_t, \mathcal{M}_{t-1})}{2.0} \in [0.0, 1.0]
  $$
  *(If clamped cosine similarity is preferred: $N_t = 1.0 - \max(0.0, \text{sim}_{\max})$).*
* **Distinction from Surprise:**
  * **Surprise without Novelty:** An event is an anomaly relative to recent context (high prediction error $S_t$), but an identical anomaly occurred 10,000 steps ago and is already stored in $\mathcal{M}$ (low novelty $N_t$).
  * **Novelty without Surprise:** The temporal state smoothly anticipates a phase transition (low prediction error $S_t$), but the resulting semantic state has never been encountered before across the entire lifetime of $\mathcal{M}$ (high novelty $N_t$).
* **Time Complexity:** $O(|\mathcal{M}| \cdot D)$. For bounded budget $K$, this is at most $O(K \cdot D)$.

---

### Factor 3: Proxy Causal Relevance ($C_t$) — Pre-Causal Heuristic & Correlation Audit

* **Strict Scope Limitation:** Continuum has **not yet implemented Causal Memory (Phase 7)**. There is no causal graph, no do-calculus, and no structural causal model at Phase 3.
* **Prohibition of False Claims:** This variable MUST be stored as `proxy_causal_score`. It must NEVER be documented as "causal effect" or "causal ground truth".
* **Mathematical Formulation for Phase 3:**  
  Two selectable implementations:
  1. **Default Baseline (C0):** $C_t = 0.0$ (deactivated).
  2. **Heuristic Proxy (C1):** Temporal Granger-heuristic / transition saliency. Measures the magnitude of state displacement induced in `TemporalState`:
     $$
     \Delta h_t = \|h_t - h_{t-1}\|_2
     $$
     $$
     C_t = \tanh\left(\frac{\Delta h_t}{\sigma_c}\right) \in [0.0, 1.0]
     $$
     *Rationale:* Events that cause substantial dynamical reorganization in the recurrent state are candidate causal changepoints.
* **Mandatory Correlation Audit:**  
  > [!IMPORTANT]
  > The Benchmark and Adversarial harnesses MUST compute and report Pearson and Spearman correlations:
  > $$\text{Corr}(S_t, C_t) \quad \text{and} \quad \text{Corr}(N_t, C_t)$$
  > If $C_t$ demonstrates high collinearity ($\text{Corr} > 0.85$) with Surprise $S_t$, Judge Agent **must consider excising factor $C_t$** from the retention model to eliminate redundancy, rather than retaining it as synthetic complexity.
* **Phase 7 Integration Hook:**  
  `AdaptiveMemory` defines an abstract protocol `CausalScorerProtocol`:
  ```python
  class CausalScorerProtocol(Protocol):
      def score_event(self, event: EventRecord, state: Tensor) -> float: ...
  ```
  In Phase 7, this hook will connect to the topological centrality score of the `CausalGraph`. In Phase 3, it defaults to `NullCausalScorer` ($C_t = 0.0$).

---

### Factor 4: Retrieval Prior / Demand Prior ($R_t$) — Online Prior Estimation

* **Demotion & Semantic Clarification (Gate Condition 4):**  
  R0 is explicitly demoted from "Retrieval Probability" to **`Retrieval Prior / Demand Prior`**.  
  Burstiness, entity recurrence, or frequency priors do NOT equal the true future retrieval probability $P(\text{retrieval} \mid x_{\le t})$. Only a strictly trained, time-lagged predictive model (R1) qualifies as an empirical probability estimator.
* **Anti-Leakage Constraint:**  
  The scoring module at time $t$ has **zero knowledge** of:
  * Future queries $q_{t + \Delta}$
  * Future benchmark needles
  * Downstream labels
* **Phase 3 Implementations:**
  1. **R0 — Heuristic Demand / Burstiness Prior:**
     Estimates demand likelihood purely from local temporal recurrence or semantic domain priors. If unconfigured, $R_t = 0.5$ (neutral uniform prior).
  2. **R1 — Trained Online Demand Predictor (Strict Rolling Temporal Split):**
     A lightweight single-layer predictor $f_\theta(x_t, h_t)$ trained strictly on historical stream sequences $t' \le t - \text{margin}$.
     Training data must be strictly lagged: queries occurring at time $t'$ can only update $\theta$ for evaluation at times $> t' + \text{delay}$.
* **Automated Leakage Audit Test:**  
  See Section 8 (Test 6).

---

### Factor 5: Normalized Online Prediction Uncertainty ($U_t$) — Recent Residual Variance

* **Epistemic Classification (Gate Condition 6):**  
  $U_t$ is strictly defined as **`Normalized Online Prediction Uncertainty`** (specifically, exponential moving average of recent forward prediction residuals).  
  **It is NOT an unproven "epistemic uncertainty" or Bayesian posterior variance.** Continuum Phase 3 makes no claims of full Bayesian uncertainty estimation.
* **Mathematical Formulation:**  
  Maintain an exponential moving average (EMA) of prediction error variance from the forward prediction head $\hat{x}_t$:
  $$
  \mu_{e, t} = (1 - \lambda) \mu_{e, t-1} + \lambda e_t
  $$
  $$
  v_{e, t} = (1 - \lambda) v_{e, t-1} + \lambda (e_t - \mu_{e, t})^2
  $$
  $$
  U_t = \frac{v_{e, t}}{v_{e, t} + \sigma_0^2} \in [0.0, 1.0]
  $$
  High $U_t$ indicates the local temporal stream is exhibiting elevated volatility/residual dispersion, signaling potential state transitions where event retention is prioritized.

## 4. Retention and Eviction Policy Engine

Importance scoring alone does not manage memory. The retention engine maps $I_t$ to an actionable state transition under bounded resources.

```text
Incoming Event e_t
        │
        ▼
Compute I_t = α S_t + β N_t + γ C_t + δ R_t + ε U_t
        │
        ▼
   [ Mode Check ]
   ├──> Threshold Mode: Is I_t >= τ ?
   │         ├── NO  ──> DISCARD
   │         └── YES ──> Insert to Memory
   │
   └──> Fixed-Budget Mode (Capacity K):
             ├── Capacity Available (|M| < K) ?
             │         └── YES ──> KEEP (Store e_t)
             │
             └── Memory Full (|M| == K) ?
                       ├── Find j* = argmin_{j} I_j in M
                       ├── Is I_t > I_{j*} ?
                       │     ├── YES ──> EVICT e_{j*} (or COMPRESS), KEEP e_t
                       │     └── NO  ──> DISCARD e_t
```

### Supported Modes
1. **`ThresholdPolicy` (`tau: float`):**
   * Absolute filtering. Any event with $I_t < \tau$ is discarded immediately.
   * *Limitation:* Does not guarantee bounded memory in adversarial regimes where all events exceed $\tau$.
2. **`FixedBudgetPolicy` (`capacity: int = K`, `eviction: Literal["min_importance", "fifo", "lru"]`):**
   * Strictly enforces $|\mathcal{M}| \le K$.
   * When $|\mathcal{M}| = K$ and $I_t > \min_{j} I_j$, the lowest-importance event is evicted.
   * Maintains an internal min-heap on $I_j$ for $O(\log K)$ eviction.

### Compression Mode Hook (Future Phase 4 / Phase 8)
When an event is selected for eviction, if `compression_enabled=True`, the evicted vector is not hard-deleted but merged into its nearest cluster centroid in a secondary compressed bank $\mathcal{M}_{\text{comp}}$. For Phase 3, the default is hard eviction (`DISCARD`).

## 5. Streaming Online API Specification

The implementation in `continuum/memory/adaptive_memory.py` must strictly adhere to the following interface:

```python
@dataclass(frozen=True)
class AdaptiveMemoryConfig:
    embedding_dim: int
    capacity: int = 1000               # Bounded budget K
    policy_mode: Literal["fixed_budget", "threshold"] = "fixed_budget"
    threshold: float = 0.5
    # Factor weights (must sum to 1.0)
    alpha_surprise: float = 0.3
    beta_novelty: float = 0.3
    gamma_causal: float = 0.0          # Default 0.0 in Phase 3
    delta_retrieval: float = 0.2
    epsilon_uncertainty: float = 0.2
    # Dynamics parameters
    ema_lambda: float = 0.05
    device: str = "cpu"

class AdaptiveMemory:
    def __init__(self, config: AdaptiveMemoryConfig) -> None: ...

    def observe(
        self, 
        event_id: int, 
        timestamp: float, 
        embedding: Tensor, 
        temporal_state: Tensor | None = None
    ) -> EventRecord:
        """
        Processes a single streaming event online.
        Computes all 5 factors, determines retention decision, and updates memory bank.
        STRICT REQUIREMENT: Operates strictly on current and past state.
        """
        ...

    def retrieve(self, query_embedding: Tensor, top_k: int = 5) -> list[EventRecord]:
        """
        Retrieves top_k records from the current active memory bank via cosine similarity.
        """
        ...

    def clear(self) -> None:
        """Resets active memory to empty state."""
        ...

    def get_stats(self) -> dict[str, Any]:
        """Returns total_observed, total_retained, total_evicted, current_size, mean_importance."""
        ...
```

## 6. Algorithmic Complexity Analysis

| Operation | Time Complexity | Space Complexity (RAM) |
| :--- | :--- | :--- |
| **Observe Step (Evaluation)** | $O(K \cdot D + H \cdot D)$ | $O(1)$ transient working tensors |
| **Eviction (Min-Heap)** | $O(\log K)$ | $O(K)$ heap indices |
| **Retrieval (Top-K)** | $O(K \cdot D + K \log(\text{top\_k}))$ | $O(\text{top\_k})$ |
| **Total Memory Footprint** | — | **Strictly bounded:** $O(K \cdot D)$ floats |

### Memory Overhead Guarantee
For $K = 10,000$ and $D = 128$ in `float32`:
* Embedding tensor storage: $10,000 \times 128 \times 4 \text{ bytes} \approx 5.12 \text{ MB}$.
* EventRecord metadata: $10,000 \times \sim 120 \text{ bytes} \approx 1.2 \text{ MB}$.
* **Total footprint:** $< 7 \text{ MB}$ regardless of whether stream length $T = 10^5, 10^7, \text{ or } 10^9$.
* *Conclusion:* Adaptive Memory overhead is orders of magnitude smaller than buffering sequence activations ($T \times D$).

## 7. Ablation Matrix & Scientific Protocol

To prove or disprove the necessity of each factor, the benchmark harness must execute the following canonical ablation configurations:

| Ablation ID | Configuration Name | Active Factors & Weights | Scientific Purpose |
| :--- | :--- | :--- | :--- |
| **A** | `TemporalState Only` | None ($K = 0$, pure recurrent baseline) | Baseline: Can recurrent state alone solve the task? |
| **B0** | `Random/FIFO Memory` | Uniform random retention / FIFO queue | Baseline: Does importance scoring beat naive retention? |
| **B1** | `Surprise Only` | $\alpha = 1.0, \beta=\gamma=\delta=\epsilon=0.0$ | Test: Does prediction error alone capture critical events? |
| **B2** | `Novelty Only` | $\beta = 1.0, \alpha=\gamma=\delta=\epsilon=0.0$ | Test: Does embedding space coverage alone suffice? |
| **B3** | `Uncertainty Only` | $\epsilon = 1.0, \alpha=\beta=\gamma=\delta=0.0$ | Test: Does model variance alone capture critical events? |
| **B4** | `Retrieval Prob Only` | $\delta = 1.0, \alpha=\beta=\gamma=\epsilon=0.0$ | Test: Can backward retrieval prior filter noise? |
| **B5** | `Proxy Causal Only` | $\gamma = 1.0, \alpha=\beta=\delta=\epsilon=0.0$ | Test: Does state displacement proxy provide any signal? |
| **B6** | `Full Composite Model`| Configured weights ($\sum = 1.0$) | Test: Does multi-factor combination outperform single factors? |

### Falsification Criteria for B6
If:
$$
\text{Accuracy}(B6) \le \max(\text{Accuracy}(B1), \text{Accuracy}(B2)) + 0.01
$$
across all canonical seeds, the multi-factor hypothesis is **REJECTED**. Continuum will revert to the minimal winning factor (e.g., $B2$ Novelty) and deprecate the remaining factors to preserve architectural parsimony.

## 8. Benchmark Test Suite Specification

The independent Benchmark Agent (`continuum-benchmark`) must implement the following 6 tests under `benchmarks/memory/`:

1. **Test 1 — Random Events Uniformity:**  
   Stream $10^4$ i.i.d. Gaussian random vectors. Verify that importance scores do not degenerate to degenerate spikes ($I_t \to 1.0$ or $I_t \to 0.0$) and retention distribution is stable across time.
2. **Test 2 — Repeated Events Redundancy Suppression (Gate Condition 2):**  
   Stream 100 distinct cluster centers, each repeated 100 times in sequence ($T = 10,000$).  
   **No pre-set retention percentage is mandated.** Instead, the benchmark measures:
   * **Redundancy Ratio (RR):** $\text{RR} = 1.0 - \frac{\text{Unique Clusters in } \mathcal{M}}{|\mathcal{M}|}$ (lower is better).
   * **Unique Information Coverage (UIC):** $\text{UIC} = \frac{\text{Unique Clusters in } \mathcal{M}}{\text{Total Unique Clusters Generated}}$ (higher is better).
   * **Fair Comparison:** Must be evaluated directly against identical-capacity Random Eviction and FIFO baselines.
3. **Test 3 — Rare Critical Needle:**  
   Stream 9,900 background Gaussian noise events with 100 structured "needle" events of distinct semantic signature. Measure Needle Retention Rate:
   $$
   \text{NRR} = \frac{|\mathcal{M} \cap \text{Needles}|}{|\text{Needles}|} \ge 95\%
   $$
4. **Test 4 — Long-Gap Retrieval with Fair Baselines (Gate Condition 3):**  
   Insert a critical event at $t = 100$. Stream $10^4$ irrelevant distractor events. Query memory at $t = 10,100$. Measure Exact Top-1 Recall and MRR (Mean Reciprocal Rank).  
   **Mandatory Fair Comparative Baselines:**
   * **Baseline A:** `TemporalState Only` ($K=0$, pure recurrent state)
   * **Baseline B-FIFO:** `FIFO Eviction Memory` (identical capacity $K$, identical embedding, precision, hardware, stream)
   * **Baseline B-Random:** `Random Eviction Memory` (identical $K$, identical stream)
   * **Baseline B-LRU:** `LRU Eviction Memory` (identical $K$, identical stream)
   * **Continuum B6:** `Adaptive Memory` (equal weights $\alpha=\beta=\gamma=\delta=\epsilon=0.2$)
   * *Note:* Baseline A is retained to demonstrate why recurrent state alone is insufficient, but it **must never serve as the sole retrieval baseline**.
5. **Test 5 — Memory Saturation & Scaling:**  
   Test memory under capacities $K \in \{10^2, 10^3, 10^4\}$. Confirm memory footprint scales strictly linearly with $K$ and remains invariant to stream length $T$.
6. **Test 6 — Formal Temporal Leakage Audit:**  
   Deliberately construct an adversarial harness that injects future query embeddings $q_{t + 1000}$ into the input stream at time $t$.  
   *Alarm Criterion:* If the memory module's importance scoring or retention accuracy increases upon injection of future queries, the test reports `LEAKAGE_DETECTED` and halts CI.

## 9. Adversarial Failure Probes (Red Teaming)

The independent Adversarial Agent (`continuum-adversarial`) will deploy the following adversarial tests under `tests/adversarial/test_adaptive_memory_probes.py`:

1. **Repetitive Flooding Attack:** Stream near-identical embeddings with infinitesimal $\epsilon$-noise. Attempt to trick Novelty $N_t$ into filling the entire capacity $K$ with redundant clutter.
2. **Importance Drift / Saturation Attack:** Inject non-stationary distributions designed to drive dynamic scales $\sigma_s \to 0$ or $\sigma_s \to \infty$, causing all scores to saturate at $1.0$ or collapse to $0.0$.
3. **Poisoned Needle Eviction:** Inject a high-importance spike immediately followed by a burst of synthetic high-importance noise to force premature eviction of the genuine needle before retrieval occurs.
4. **Numerical Stability Probe:** Feed subnormal floats, NaN embeddings, and near-zero norm vectors to verify graceful exception handling (`ValueError`) without state corruption.
