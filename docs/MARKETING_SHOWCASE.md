## 四、 60 秒极速上手：今天就让你的 Cursor 进化为“最强大脑”！

只需在终端敲入一行命令：

```bash
curl -fsSL https://raw.githubusercontent.com/reacherwu/continuum/main/install.sh | bash
```

然后在你的 Cursor（`~/.cursor/mcp.json`）或 Claude Desktop 中加入这 4 行配置：

```json
{
  "mcpServers": {
    "continuum": {
      "command": "continuum-cli",
      "args": ["mcp"]
    }
  }
}
```
