# Benchmark policy

Benchmarks will cover needle retrieval, temporal gap, multi-hop causal chains, memory revision, and memory scaling. Every comparison records dataset, seed, precision, parameters, hardware, batch size, latency, throughput, and memory. A comparison with mismatched conditions is labelled **NOT DIRECTLY COMPARABLE**.

See `benchmarks/baselines.yaml` for the baseline registry; missing baselines are explicitly marked rather than simulated.
