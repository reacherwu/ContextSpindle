# ContextSpindle v0.3.0 — durable task continuity

This is the first release under the **ContextSpindle** product definition. The earlier `v0.2.0` GitHub release belongs to the historical DiffHound PR-review project; it is not a release of the current task-ledger product.

## What is included

- A local, append-only, versioned task ledger independent of the bounded retrieval cache. Tasks track goals, completion criteria, status, next action, decisions, blockers, dependencies, and evidence.
- Task-aware context assembly under a conservative UTF-8 byte budget, with required state retained and optional omissions reported.
- Task verification, backup, and restore; CLI and MCP task operations; continued bounded-memory tools.
- macOS and Linux source builds. The legacy `continuum-cli` command, Rust crate names, Python import, and `.continuum/` snapshot path remain for compatibility.

## Install and start

Requires a current stable Rust toolchain. Download the source archive attached by GitHub to this release, unpack it, and from its root run:

```sh
cargo build --release --locked --bin contextspindle
./target/release/contextspindle init .
./target/release/contextspindle task create "Your goal" --criteria "How completion is checked"
./target/release/contextspindle task inbox 10
```

The [README](https://github.com/reacherwu/ContextSpindle#readme) and [agent protocol](https://github.com/reacherwu/ContextSpindle/blob/main/docs/AGENT-PROTOCOL.md) cover task updates, handoffs, MCP, and recovery. No prebuilt executable is attached to this release; source archives are the supported release artifact.

## Validation and limits

The Rust workspace tests and Python test suite pass. A [reproducible 1,000-task benchmark](https://github.com/reacherwu/ContextSpindle/blob/main/docs/TASK-LEDGER-BENCHMARK.md) measured a selected 2,048-byte context at 34.23 ms median over 11 warm-cache Apple M4 release-CLI runs; see the linked raw data and methodology before generalizing. The benchmark ran against the 0.2.0 codebase before the version/branding-only update to 0.3.0. It did not test Linux performance or multi-year persistence.

The ledger is local and Git-ignored. For long-term continuity, protect off-device backups and periodically test restore. Tasks that an agent never records cannot be recovered. The byte ceiling is not a model-token guarantee.
