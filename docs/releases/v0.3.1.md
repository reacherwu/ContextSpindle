# ContextSpindle v0.3.1 — license and community documentation correction

This patch release does not change task-ledger or retrieval behavior. It corrects the source archive's incomplete `LICENSE` file by replacing it with the complete, unmodified GNU AGPL-3.0 text. The earlier `v0.3.0` tag is left unchanged for historical reference; use this release for the corrected license text.

The contribution guide now covers task-ledger invariants, tests, benchmark evidence, and data hygiene. The Code of Conduct includes scope and attribution. A new security policy points to GitHub private vulnerability reporting, which is enabled for the repository. The website's old legal-boundary page and `docs/LICENSE_GUIDE.md` no longer make categorical integration or commercial-license promises; consult the license text and qualified counsel for specific cases.

## Install

Download this release's GitHub-generated source archive and, from its root, run:

```sh
cargo build --release --locked --bin contextspindle
./target/release/contextspindle version
```

This source-only release supports macOS and Linux builds; no prebuilt binaries are attached. The [v0.3.0 notes](https://github.com/reacherwu/ContextSpindle/releases/tag/v0.3.0) describe the product and its measured workload. Those measurements were not rerun for this documentation-only patch and are not new `v0.3.1` performance claims.
